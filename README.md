## 📋 Deskripsi Proyek

**Sistem Inventaris Ruangan Berbasis PWA** adalah aplikasi sederhana yang digunakan untuk membantu melakukan pendataan dan pengelolaan barang inventaris yang terdapat di beberapa ruangan.

Aplikasi ini dibuat menggunakan teknologi **Progressive Web App (PWA)** sehingga dapat memberikan pengalaman seperti aplikasi pada perangkat komputer maupun smartphone.

Sistem ini dapat digunakan untuk mencatat barang, melihat kondisi barang, mengelompokkan barang berdasarkan ruangan, serta mengelola data inventaris dengan lebih mudah.

---

## 🎯 Tujuan

Tujuan pembuatan proyek ini adalah:

- Membuat aplikasi inventaris sederhana berbasis PWA.
- Mempermudah proses pendataan barang.
- Mempermudah pencarian dan pengelolaan data inventaris.
- Menampilkan kondisi barang berdasarkan statusnya.
- Menerapkan teknologi Progressive Web App dalam sebuah proyek sederhana.

---

## ⚙️ Fitur Aplikasi

Beberapa fitur yang tersedia dalam aplikasi:

- ➕ Menambahkan data inventaris.
- ✏️ Mengedit data inventaris.
- 🗑️ Menghapus data inventaris.
- 🔍 Mencari data barang.
- 🏫 Memilih ruangan inventaris.
- 📦 Menampilkan jumlah barang.
- ⚠️ Menampilkan kondisi barang.
- 💾 Penyimpanan data pada browser.
- 📱 Tampilan responsif.
- 🌐 Dukungan Progressive Web App (PWA).
